# Brief: Plugin Era (media-player visualizer plugins, 1999-2004)

**Tells**
1. The whole frame moves: a feedback image warped every frame by a coarse mesh (zoom, rotation, swirl, ripple), so trails stream outward or spiral.
2. The warp is per vertex on a coarse grid, so the motion has a soft, slightly faceted quality.
3. Bright waveforms drawn on top every frame (a horizontal scope, a circular scope, a dot spray), feeding the trails.
4. Colour slowly decays and shifts hue in the feedback.
5. Post switches flicker in on the beat: centre darkening, "video echo" (a mirrored, zoomed copy of the frame blended in), brightening, full colour inversion for a beat.
6. A slightly soft image (a small buffer stretched to the screen).
7. Every so often it blends into a completely different preset over a couple of seconds.

**Anti-tells:** clean crisp vector graphics, static frames, modern smooth gradients, obvious repetition.

**Music map:** bass: zoom and warp amount; kick: wave brightness and thickness flash; snare: rotation kick; hats: dot spray; bar: echo orientation flips; phrase: blend to the next preset; build: zoom speeds up; drop: hard cut to a new preset plus one beat of inversion; breakdown: slow warp, darken centre on; silence: trails decay to black.

**Variety:** at least 8 preset recipes (each a warp field + wave + post switches + hue drift), random-but-deterministic order per phrase.
