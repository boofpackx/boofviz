# Brief: Glowstick Rave (late-90s raves)

**Tells**
1. Total darkness, the only light from chemical glowsticks: soft glowing cores with harder bright centres.
2. Long-exposure style trails: loops, figure eights, circles, flowers, swung around invisible hands.
3. Classic glowstick colours: green, magenta, blue, yellow, orange, white.
4. Pairs of sticks moving in mirror symmetry (one in each hand), sometimes on strings (poi-like circles).
5. A faint haze lit by the sticks.
6. Trails fade over about a bar.

**Anti-tells:** laser-sharp lines, neon tubes, LED pixels, visible people.

**Music map:** each stick's path is locked to the beat (one loop per beat or per two beats); kick: brightness flare; hats: tiny wrist flicks; bar: pattern changes (circles → eights → flowers → waves); phrase: more dancers (sticks) join; drop: sticks thrown up spinning end over end, then caught; breakdown: one pair, slow wide circles; silence: sticks hang, glowing.

**Variety:** at least 6 patterns, 1-4 pairs, colour sets from the palette, string vs hand.
