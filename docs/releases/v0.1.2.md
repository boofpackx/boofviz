BOOFVIZ 0.1.2 makes music on Windows work with no setup at all.

## Install

Download **BOOFVIZ-Setup-0.1.2.exe** below and run it (it updates earlier versions in place). The installer isn't code-signed yet: if Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

## New

- **No Spotify setup needed:** BOOFVIZ follows whatever is playing through Windows (Spotify Free or Premium, TIDAL, Apple Music, Deezer, or YouTube and SoundCloud in a browser). Song, position, play / pause and album cover all come from there, with no developer app, no Client ID and no login, so there are no Spotify rate limits either. Logging in to Spotify is still there, optional, for exact song names and timing.
- **Play, pause and skip without Premium:** the Lyrics tab's Prev / Play / Next control your player through Windows.
- **Album cover colours** (Master tab): every look takes the main colours of the playing song's cover, easing over as songs change.
- **Automatic lyric timing** (on by default): BOOFVIZ measures, at the start of each song, how late it is heard compared with what the player says, and moves the lyrics to match. The Offset slider still fine-tunes on top (and handles speaker or Bluetooth delay).

## Good to know

- Lyrics are copyrighted: showing them at a public or commercial event needs a licence from the rights holders.
- Ableton Link is not included in this build (the Link SDK is GPL-licensed).
